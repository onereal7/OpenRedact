MODIFICATIONS
================================================================================

This copy is a fork of Open Redact by Tim Sabanshi
(https://github.com/tsabkuro/OpenRedact), which is the original work. The
original author retains the copyright in the original work above and in every
source file that still carries their copyright notice.

Modifications in this fork (see the commit history for details):

  - The exported PDF is saved with garbage collection, so content that was
    removed by a redaction is no longer present in the bytes of the file.
  - Redaction options are stated explicitly instead of relying on the
    engine's defaults.
  - The page and its assets are cached properly, so the tool keeps working
    when the network is unavailable.
  - A failed document load is reported in the interface instead of only in
    the browser console.

The original work remains available at the address above. Anyone who wants
the unmodified version should go there.
